# ✈ מעקב טיסות מישראל

מערכת שסורקת כל שעה מחירי טיסות מנתב"ג לכל היעדים שהוגדרו, אצל כל חברות התעופה.
היא שומרת את כל ההיסטוריה ומתריעה כשקורה משהו מעניין. בנוסף היא לומדת איך כל חברה מעלה ומורידה מחירים.

## מה המערכת עושה

| התראה | מתי |
|---|---|
| ✈️ **טיסה חדשה פורסמה** | הופיעה טיסה שלא הייתה בסריקות הקודמות של אותו יעד ותאריך, כלומר החברה פתחה אותה עכשיו למכירה |
| 🆕 **קו חדש** | חברה נראית בפעם הראשונה טסה ליעד |
| 📉 **ירידת מחיר** | המחיר ירד לפחות ב-8% וגם לפחות ב-15$ מאז הבדיקה הקודמת (ניתן לשינוי) |
| 🏆 **שפל** | המחיר הנמוך ביותר שנראה אי פעם לאותה טיסה |
| ⏰ **רגע אחרון** | המראה בתוך 7 ימים, ומחיר ברבע הזול ביותר שנראה לאותו יעד |

**למידת דפוסי תמחור:** לכל חברת תעופה המערכת מחשבת את הנתונים הבאים:
- עקומת מחיר לפי מספר הימים שנותרו עד הטיסה, ומתוכה חלון ההזמנה הזול ביותר.
- האם החברה מוזילה או מייקרת ברגע האחרון.
- כמה פעמים ביום המחיר משתנה, ומה הגודל הממוצע של ירידה ושל עלייה.
- באיזו שעה ובאיזה יום בשבוע ירידות מחיר קורות בדרך כלל.

מתוך זה כל טיסה מקבלת המלצה, **לקנות** או **לחכות**.

ההתראות מוצגות בלוח הבקרה, ואפשר לקבל אותן גם בטלגרם.

## מאיפה מגיעים הנתונים

רוב חברות התעופה חוסמות סריקה אוטומטית של האתרים שלהן, ותנאי השימוש שלהן אוסרים אותה. לכן המערכת מושכת את הנתונים דרך ממשקי API מסודרים שמכסים את כל החברות שטסות מישראל, כולל אל על, ישראייר, ארקיע, וויז, ריינאייר, איזיג'ט, אגיאן ולופטהנזה:

1. **SerpApi (Google Flights)** – מחירים חיים, עדכניים ומדויקים. כולל 250 חיפושים חינם בחודש, ומעבר לזה בתשלום. הרשמה: https://serpapi.com
2. **Travelpayouts (Aviasales)** – חינמי. המחירים בו מגיעים ממטמון של חיפושים שעשו משתמשים אחרים, ולכן הוא משמש כמקור משלים. הרשמה: https://www.travelpayouts.com

> 💚 **הגרסה מוגדרת לעבודה בחינם:**
> - **Travelpayouts (חינם):** סורק את כל 15 היעדים ו-16 התאריכים כל שעה, עד 60 בדיקות בריצה.
> - **SerpApi:** מוגבל ל-8 בדיקות ביום ול-240 בחודש. זה פחות מ-250 החיפושים שבחבילה החינמית, כך שלא תחויבו.
>   הבדיקות האלה משמשות לאמת במחיר חי את הדילים הזולים ביותר שנמצאו.
> - את המגבלות אפשר לשנות בקובץ `config.json`, בשדות `paid_daily_limit` ו-`paid_monthly_limit`.

## התקנה מהירה

### אפשרות א': Docker (מומלץ לשרת)
```bash
cp .env.example .env      # ומלאו את המפתחות
docker compose up -d --build
```
פתחו בדפדפן: http://SERVER_IP:8080

### אפשרות ב': פייתון ישירות (ללא תלויות חיצוניות, Python 3.9+)
```bash
export SERPAPI_KEY=xxxx
export TRAVELPAYOUTS_TOKEN=yyyy
python3 -m app.main serve
```

### לנסות קודם בלי מפתחות (נתונים מדומים)
```bash
FT_DEMO=1 python3 -m app.main seed-demo 40    # ממלא 40 ימי היסטוריה מדומה
FT_DEMO=1 python3 -m app.main serve
```
במצב ההדגמה יש 8 חברות מדומות, ולכל אחת אסטרטגיית תמחור אחרת. כך רואים איך מודול הלמידה מזהה דפוסים.
לפני מעבר לנתונים אמיתיים צריך למחוק את `data/flights.db`.

## התראות לטלגרם
1. בטלגרם, שלחו ל-@BotFather את הפקודה `/newbot`. תקבלו טוקן ושימו אותו ב-`TELEGRAM_BOT_TOKEN`.
2. שלחו הודעה כלשהי לבוט שיצרתם.
3. היכנסו לכתובת `https://api.telegram.org/bot<TOKEN>/getUpdates` והעתיקו את `chat.id` אל `TELEGRAM_CHAT_ID`.

## הגדרות (`config.json`)
- `destinations` – רשימת היעדים בקודי IATA.
- `scan.days_ahead` – באילו מרחקים מהיום לבדוק (1, 2, 3 … 330 ימים קדימה).
  מעקב אחרי 270–330 יום קדימה הוא מה שמאפשר לתפוס את הרגע שבו חברה פותחת לוח זמנים חדש למכירה.
- `scan.interval_minutes` – כל כמה זמן לסרוק (ברירת מחדל: 60).
- `alerts.price_drop_percent` ו-`alerts.min_drop_amount` – הרגישות של התראות ירידת המחיר.

## פקודות
```
python3 -m app.main serve        # לוח בקרה + סריקה אוטומטית כל שעה
python3 -m app.main scan         # סריקה אחת (אפשר גם להפעיל מ-cron)
python3 -m app.main seed-demo 40 # היסטוריה מדומה
```

## מבנה
```
app/
  main.py          שרת ה-Web, ה-API והמתזמן
  scanner.py       ריצת סריקה ותקציב הבקשות
  detector.py      זיהוי טיסות חדשות, ירידות, שפל ורגע אחרון
  learner.py       למידת דפוסי התמחור של כל חברה והמלצת קנה/חכה
  notify.py        טלגרם
  providers/       SerpApi, Travelpayouts, ספק הדגמה
  static/index.html  לוח הבקרה
data/flights.db    כל ההיסטוריה (SQLite)
```

## הערה על דיוק
- הלמידה משתפרת עם הזמן. אחרי שבוע היא נותנת כיוון ראשוני, ואחרי חודש עד חודשיים התמונה כבר אמינה.
- המחיר הסופי נקבע תמיד באתר ההזמנה. Travelpayouts מבוסס על מטמון של חיפושים, ולכן המחיר שהוא מציג עלול להיות לא מעודכן.
